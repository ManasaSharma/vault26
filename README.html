frontend-systems-lab

Personal portfolio + an evolving engineering lab, built with Next.js and TypeScript.

Next.js 16 TypeScript Tailwind CSS React Query Zustand Jest + RTL

What this is

A frontend-only portfolio site with two parts:

  • Portfolio — About, Experience, Skills, Projects, Contact.
  • Engineering Lab — a growing set of small, interactive case studies: a real-world frontend problem, an approach, and a fix, each with a live demo.

The "backend" is mocked using real Next.js API routes (src/app/api/*/route.ts) that return JSON with simulated network delay and occasional simulated errors, consumed on the frontend via React Query. There is no external database or real backend service.

Prerequisites

ToolVersionNotes
Node.js20.xSee .nvmrc below — do not use Node 18, the build will fail.

Gitany recentTo clone the repo.
Node version note: This repo has its own .nvmrc file pinning Node 20.20.2. It does not change your global Node version — it only applies when you cd into this folder and run nvm use.
npm registry note: This repo has its own .npmrc file pointing npm at the public registry (registry.npmjs.org). This only takes effect when npm commands are run from inside this folder — it does not change any global or other-project npm configuration.

1. Clone the repo

git clone <your-github-repo-url>
cd frontend-systems-lab

2. Use the correct Node version

nvm install   # installs the version pinned in .nvmrc, if you don't already have it
nvm use       # switches this shell to that version
node -v       # should print v20.20.2

3. Install dependencies

npm install

This installs everything from the public npm registry (see the note above about .npmrc).

4. Run the app locally

npm run dev

Then open http://localhost:3000 in your browser.
